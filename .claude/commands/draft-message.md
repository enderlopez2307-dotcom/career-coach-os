---
description: A reply or a first message to a new person — drafted and added to the review queue. Never a nudge to someone who hasn't replied.
---

**Agent:** `coach` · runs in this session.
**Usage:** `/draft-message <context — who, what happened, what's needed>`

## Task
1. Read whatever context exists: the thread it's replying to, the
   opportunity note, `Tracking/Contacts.md` for the relationship.
2. Apply the two-fact rule: at least one fact that took real work to find,
   one thing only the candidate could say.
3. Match the register in `config/voice.md` for this message type (DM vs.
   email vs. application answer).
4. Run `/voice-check`.
5. Add to `vault/Outreach Drafts/_queue.md`, status `needs review`,
   `Channel` set (ask if it's not obvious from context), `Draft ref` set to
   a new Gmail draft's link if the channel is email, or the LinkedIn
   profile/message URL if it's LinkedIn (the message itself stages later,
   in `/review-queue`), and a "before you send" line naming anything to
   verify or personalize further.
